# HTune application icon

`htune-icon-source.png` is the exact transparent PNG supplied by the user on 2026-10-19. It depicts a black vinyl record and a cream H-shaped musical note. It has not been redrawn, recolored or composited.

`htune.ico` is a Windows ICO conversion of that source, with 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel entries. `src/app.rc` embeds it for the window, taskbar, tray and executable.

The earlier MusicStage icon files remain source history only and are not referenced by the current executable.
